ToDo-App als Android-PWA veröffentlichen (GitHub Pages)

Schritt 1: Repository vorbereiten
Lege in deinem GitHub-Konto ein neues öffentliches Repository an, zum Beispiel "todo-app".
Lade alle sechs Dateien aus diesem Paket in das Hauptverzeichnis (Root) hoch:
index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, seiffertsupdate-icon.png

Per Kommandozeile auf deinem Arch-System:
  git clone git@github.com:haigo-cyber/todo-app.git
  cd todo-app
  (Dateien hineinkopieren)
  git add .
  git commit -m "ToDo PWA"
  git push

Schritt 2: GitHub Pages aktivieren
Im Repository: Settings -> Pages -> Source: "Deploy from a branch",
Branch: main, Ordner: / (root), speichern.
Nach ein bis zwei Minuten ist die App erreichbar unter:
  https://haigo-cyber.github.io/todo-app/

Schritt 3: Google OAuth freischalten (wichtig!)
In der Google Cloud Console (console.cloud.google.com):
APIs und Dienste -> Anmeldedaten -> deine OAuth-Client-ID öffnen.
Unter "Autorisierte JavaScript-Quellen" hinzufügen:
  https://haigo-cyber.github.io
(Nur die Domain, ohne Pfad. Ohne diesen Eintrag schlägt die Anmeldung
mit einem Fehler wie "origin_mismatch" fehl.)

Schritt 4: Auf dem Android-Gerät installieren
Die URL in Chrome öffnen, einmal anmelden und testen.
Dann im Chrome-Menü (drei Punkte): "Zum Startbildschirm hinzufügen"
bzw. "App installieren". Die App erscheint mit eigenem Icon im
App-Drawer und startet ohne Browserleiste.

Hinweise
- Updates: Einfach neue Dateiversionen ins Repository pushen. Wenn du
  sw.js änderst, die Versionsnummer in der Zeile const CACHE = "todo-shell-v59"
  hochzählen (v60, v61, ...), damit alte Caches ersetzt werden.
- Die Daten der App liegen weiterhin ausschließlich in deinem
  Google-Konto (Tabelle, Kalender, Tasks). GitHub hostet nur die Hülle.
- Falls du das Repository lieber privat halten willst: GitHub Pages
  für private Repos erfordert einen kostenpflichtigen Plan. Alternative
  wäre z. B. Cloudflare Pages oder Netlify (beide kostenlos, auch mit
  privaten Repos).

Neu in dieser Version (Datensicherheit)
- Speichern erfolgt jetzt ohne vorheriges Löschen der Tabelle. Ein
  Verbindungsabbruch beim Speichern kann die Daten nicht mehr leeren.
- Schutzabfrage: Würde ein leerer Datenbestand einen zuvor gefüllten
  überschreiben, fragt die App ausdrücklich nach.
- Automatisches Backup: Beim App-Start wird geprüft, ob das letzte
  Backup älter als 7 Tage ist. Dann wird in deinem Drive eine Kopie
  "ToDo Backup JJJJ-MM-TT" angelegt; die 5 neuesten Kopien bleiben
  erhalten, ältere werden gelöscht.
- In den Einstellungen (Konto): "Jetzt sichern" für ein sofortiges
  Backup und "Exportieren" für einen JSON-Download aufs Gerät.
- Wiederherstellung: Backup-Kopie in Drive öffnen, Inhalte prüfen.
  Am einfachsten die defekte Tabelle "ToDo App Data" umbenennen
  (z. B. in "ToDo App Data defekt") und die Backup-Kopie in
  "ToDo App Data" umbenennen. Danach in der App unter Konto einmal
  abmelden und neu anmelden — dabei sucht die App die Tabelle anhand
  des Namens neu und verbindet sich mit der Kopie. Unabhängig davon hat
  jede Google-Tabelle unter Datei -> Versionsverlauf eine eigene
  Historie zum Zurückspringen.
